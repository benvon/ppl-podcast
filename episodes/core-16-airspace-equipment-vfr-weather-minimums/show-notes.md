# Airspace, Equipment, and VFR Weather Minimums

**Episode:** 16
**Version:** 0.1.1

## In this episode

One fictional daytime cross-country turns airspace into a repeatable decision: locate the airplane in three dimensions, establish the communication or clearance required for entry, match the pilot and equipment to the full route, and apply the correct VFR visibility and cloud minimums. The route climbs from Class G into Class E, passes near Class C and beneath a Class B shelf inside its Mode C veil, and approaches a Class D destination. Lowering weather, special use airspace, an MTR, and a TFR test the plan and clarify which rules belong to each category.
